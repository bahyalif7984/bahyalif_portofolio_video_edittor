How to install into your current portfolio:
1. Replace index.html, styles.css, script.js.
2. Copy assets/video-posters into your existing assets folder.
3. Copy assets/videos into your existing assets folder.
4. KEEP all your other existing assets (profile.webp, service images, CV, artwork, etc.).

Do not delete the old assets folder because this package only contains the new video-related assets.
